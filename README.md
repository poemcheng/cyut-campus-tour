# 朝陽漫遊｜朝陽科技大學校園導覽

依使用者提供的 `sch_city-main.zip` 參考製作。保留 Three.js + React + TypeScript + Vite 的互動校園導覽方向，重新整理朝陽科技大學資料、場景及介面，沒有使用南海校區的模型、照片、座標或開放時間。

## 開啟與開發

公開網站：[GitHub Pages](https://poemcheng.github.io/cyut-campus-tour/) · [原始碼](https://github.com/poemcheng/cyut-campus-tour)

需要 Node.js 22.18 以上（測試使用內建 TypeScript 支援）。在本資料夾開啟終端機：

```sh
npm ci
npm run dev
```

開啟終端機顯示的網址。可使用 `npm run build` 產生 `dist/`，再用 `npm run preview` 預覽。`dist` 可交由任何靜態網站伺服器提供服務；請勿直接雙擊 HTML，以免瀏覽器阻擋模組。網頁字型取自 Google Fonts，無網路時使用系統字型；程式與校園圖會隨建置一併提供。

## 已完成功能

- 30 個朝陽地點（含 13 處演講廳、禮堂與會議廳）、中英名稱、分類、簡介及官方資料連結。
- 有高低差的 Three.js 校園地形；可旋轉、縮放、俯視、側視，並切換 1×／2× 地形垂直倍率。
- 11 棟建築的地上樓層與地下層、翼樓、中庭、入口、樓板、梁柱、兩跑樓梯與電梯核心；可選樓層剖視。
- 建築點選、鏡頭聚焦、標籤避讓與分類淡化。
- 地點名稱、英文及教室代碼搜尋；支援 `/` 搜尋快捷鍵。
- 三條主題參訪路線及自訂起終點，使用含高程的 3D A\* 示意路網，提供一般步行與避開戶外樓梯的示意模式。
- 導覽播放與暫停；可選瀏覽器中文語音，語音支援依裝置而定。
- 本機收藏、可分享的地點網址參數、官方校園圖縮放。
- 手機版導覽面板、交通與無障礙資訊連結。

## 資料與示意邊界

建築配置與外觀參考官方平面、導覽與透視圖；區段落差依官方無障礙圖的 1、7、3、5 公尺標示。以入口通路為模型零點，推導四區相對高程 +1、+8、+11、+16 公尺。相對零點、區界、水平尺度、樓高、階數、坡道尺寸與室內梁柱及梯間配置為明確標示的推估，沒有使用校方 BIM、GIS 或測繪檔。路線表達參訪順序與示意路網，不提供實測距離、步行時間、即時定位或無障礙路徑保證。現場動線、開放時間與使用規範請依校方最新資訊。

## 修改與驗證

- `src/data.ts`：地點文字、資料來源與示意座標。
- `src/CampusScene.tsx`：場景、樓層剖視與鏡頭控制。
- `src/campusModel.ts`：分層地形、階梯、坡道與建築構造幾何。
- `src/structure.ts`：區段高程依據、樓層、平台、入口及 3D 路網。
- `src/pathfinding.ts`：示意路網與 A\*。
- `src/main.tsx`、`src/style.css`：導覽介面與響應式樣式。
- `npm test`：578 組 3D 路網模式／起終點，檢查最短路徑與樓梯排除；另驗證地基平整、樓層與地下室、剖視遮擋及地形挖空還原、有限幾何座標與合併網格預算。
- `npm run build`：TypeScript 檢查與正式建置。

不需要任何地圖 API 金鑰。網站不要求定位、相機或登入；收藏只保存在使用者瀏覽器。

## GitHub Pages 發佈

1. 執行 `npm ci`，再執行 `npm run build:pages`。
2. 將原始碼及產生的 `docs/` 提交到 GitHub。
3. 在儲存庫 Settings → Pages 選擇 Deploy from a branch，指定 `main` 分支的 `/docs` 資料夾並儲存。
4. 發佈網址為 `https://poemcheng.github.io/cyut-campus-tour/`。

`docs/.nojekyll` 關閉 Jekyll 處理。Vite 使用相對資產路徑，同時相容根目錄與 GitHub Pages 子路徑。更新程式後需重新執行 `npm run build:pages` 並提交 `docs/`。公開儲存庫不包含 `.openai/` 平台設定或任何憑證。

## 高程與結構重建

使用者確認：沒有 CAD／BIM 或測量資料，依官方公開圖資重建，推估尺寸必須標示。

| 資料                                                                             | 已確認                                                     | 推估或模型設定                                                          |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------- |
| [官方無障礙設施圖](https://web.cyut.edu.tw/p/412-1000-4555.php?Lang=zh-tw)       | 圖上標示區段落差 1、7、3、5m，並可辨識中央步道與宿舍前階梯 | 入口相對零點、區段邊界、水平定位、階數、梯寬與繞行坡道幾何              |
| [官方樓層簡介](https://web.cyut.edu.tw/p/412-1000-4556.php?Lang=zh-tw)           | 各棟最高樓層、已列地下層、廳館所在樓層與房號               | 一般樓高 3.5 模型單位、航空 4、體育館 4.2；梁柱與室內樓梯、電梯平面位置 |
| [官方校園透視圖](https://web.cyut.edu.tw/p/412-1000-4554.php?Lang=zh-tw)與導覽圖 | 建築相對配置、鐘樓等外觀特徵                               | 翼樓、凹口、屋頂細節與門廊尺寸                                          |

「地形垂直 2×」只強調地形落差，不代表等比例測繪；可切回 1×。切換樓層剖視會移除上方樓層及該層外牆，顯示樓板、柱、兩跑樓梯、平台與電梯核心。地下層剖視會暫時挖空所選建築周邊地形，關閉後還原。

避開樓梯模式僅排除示意圖中的戶外階梯邊，不代表坡度、入口、無障礙設施與現況通行已驗證。路線終點為推估的建築入口；室內房間精確位置與室內逐步路線仍需校方平面圖及現場核對。模型單位的水平尺度沒有經測繪校準，因此不顯示精確路程或坡度百分比。
